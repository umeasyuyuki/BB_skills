# CTA・外部導線ポリシー

Threads 投稿と Note 記事の末尾に入れる案内文の正本。Threads 最終リプは **Note 案内（メイン）+ LINE OC 匂わせ（サブ）** の D-2 二段構成。Note 末尾は公式 LINE オープンチャットへの実リンクを入れる。

## 固定プレースホルダ

| 用途 | プレースホルダ |
|---|---|
| Note 記事 URL | `【★Note URL を貼る★】` |

公式 LINE オープンチャット:

- 名称: オープンチャット「サイエンスベースフィットネス@Brain Bulking」
- URL: `https://line.me/ti/g2/lmmjCh0V39BIgClQxQmsm4Hb-G8Hb7VFsnVOuw?utm_source=invitation&utm_medium=link_copy&utm_campaign=default`

「プロフィールリンク / 公式リンク集 URL を貼る」プレースホルダは廃止。Threads では本文中に LINE URL を貼らず、「プロフィールの相談室」「プロフィールから」という言い回しでプロフィール欄経由の動線にする。Note 末尾だけは上記の公式 LINE オープンチャット実リンクを使う。

## 設計思想

- Threads 最終リプは Note への深掘り誘導をメインに、LINE オープンチャットを「プロフィール（欄）の相談室」として控えめに添える
- LINE 直 URL は Threads には貼らない。Note 末尾のみ公式 LINE オープンチャット URL を貼る
- 誘導は「入ってください」型ではなく、「ゆる〜く議論しています」「見るだけ参加大歓迎」のトーン
- 健康・栄養・ヘルスケア領域では、医療相談や個別診断ではないことを Note 末尾で明記する
- LINE OC は「相談室」「議論」「見るだけ参加歓迎」と表現し、商業的誘導感を出さない

## Threads 最終リプ（必須、D-2 二段構成）

Threads の最終リプは **Note 案内（メイン）+ LINE OC 匂わせ（サブ）** の二段構成にする。間に区切り（`ーーー` または空行 2 行）を入れる。

文字数目安: **240〜300 字**（メイン 100-150 字 + 区切り + サブ 100-150 字）。

### LINE OC 匂わせ部分の固定文言

LINE OC を匂わせるサブ部分は基本的に共通文言で運用する。バリエーションを作る場合も以下のキー要素は崩さない。

- 質問文のフック（「これ食べていい？」「サプリいる？」のような体づくり目線の素朴な問い）
- 場所の表現（「プロフィールの相談室」固定）
- 温度感（「ゆる〜く議論しています」固定）
- 参加の敷居の低さ（「見るだけ参加も大歓迎です」固定）

NG: 「今すぐ参加」「全員入って」「LINEはこちら」「URLはプロフィールから↓」

## Note 末尾構造

Note の末尾は **関連リンク** セクション。LINE オープンチャットの言及は Threads より少し前向きにし、公式 LINE オープンチャットへの実リンクを入れる。

見出しは `## 関連リンク` で固定。

## 禁止事項

### Threads 全体で禁止

- `line.me` URL の直貼り（プロフィール欄経由のみ）
- 強い誘導語: `完全無料` / `日本最先端` / `入っていることがステータス` / `読んでいるだけで判断できる` / `今すぐ参加` / `全員入って` / `👇`
- Note URL とは別に LINE 直 URL を貼ること
- 「プロフィールから↓」のような露骨な誘導記号

### Note 末尾で禁止

- 指定された公式 LINE オープンチャット以外の LINE URL
- 強い参加命令（「必ず入ってください」「登録必須」）
- 過剰な限定感（「先着 N 名」「今だけ」）
- 効果保証に見える表現（「入れば筋肉がつく」「効果が出ます」）
- 医療相談や個別診断を受けられるように見える表現
