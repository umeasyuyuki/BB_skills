# 文体・トーンガイド（標準語ベース）

bb-note-threads スキル全体の口調・トーン指針。**全媒体・全パートを標準語で運用する**。旧仕様の関西弁レベル 2 / ハイブリッド関西弁は完全廃止。

## 基本方針

| 媒体 / パート | トーン | 役割 |
|---|---|---|
| Threads ツリー本体（親 + 本体リプ） | 標準語・断定・体言止め可・思想を叫ぶ BB トーン | 短文で殴る |
| Threads 最終リプ | 標準語・温かい・ゆるい | Note 案内 |
| Note 地の文 | 標準語・落ち着いた論証・ファクトで殴る | 深掘り |
| Note 主張ブロック・体験談 | 標準語・断定・体言止め | 熱量を担う |
| Note 末尾の関連リンク案内 | 標準語・温かい・ゆるい | 公式リンク集への案内 |

## BB のスタンス（口調を超えた根幹）

- 京大院生 + 薬剤師という事実を、論文・市場・規制という具体物で裏打ちする
- 「情弱ビジネスを終わらせる」という思想は維持する
- 敵は「知らないにつけ込んで金を抜く側」、味方は「読者と一緒に最先端を翻訳する自分たち」
- 怒りは事実で表現する。罵倒・人格否定はしない
- 数字 / 時間軸 / 損失感 のいずれかを必ず含める

## 標準語 BB トーンの基本フォーム

### 推奨

- 断定: 「〜である」「〜だ」「〜になる」「〜していい」
- 体言止め: 「年間で数万円の差。」「これが現実。」
- 反語: 「これを知らずに飲み続ける選択肢があるのか」
- 名詞文: 「論文と現場の距離、平均 10 年。」
- 短い問い → 即断ち切る回答: 「正解は何か。事実だけで決める。」

### 禁止

- 関西弁の語尾: 「〜やで」「〜ねん」「〜やん」「〜やろ」「ほな」「せやから」「ほんま」「めっちゃ」「ええ感じ」など一切 NG
- AI っぽい抽象語: 「最適化」「アプローチ」「フレームワーク」「ソリューション」「コミットメント」
- 曖昧表現: 「ケースバイケース」「一概には」「人によりますが」「個人差があります」
- 客体化: 「あなた」「皆様」「読者の方」「視聴者の皆さん」（案内文では完全 NG、本文でも極力避ける）
- 過剰な疑問形・連投: 「〜でしょうか？」「〜ですよね？」を 1 投稿に 2 つ以上
- 自虐 / へりくだり: 「未熟ですが」「私たちごときが」

## 「俺ら／俺たち」の使い分け

- **本文（Threads 親 + 本体リプ、Note 地の文）**: BB の主体性を示すため使用可。「俺らが翻訳する」「俺らが証明する」
- **Threads 最終リプ / Note 関連リンク案内**: 完全に封印。案内文は押し込む場ではなく、必要な人があとで見に行ける入口にする

## 温かい案内トーン（最終リプ・関連リンク案内専用）

案内文は**「売り込まず、置いておく」**書き方を徹底する。

| ❌ 強い誘導 | ✅ 温かい案内 |
|---|---|
| 今すぐ参加してください | 気になるテーマがあればのぞいてみてください |
| 全員入ってください | 気になるところだけ読んでもらえれば大丈夫です |
| 参加しないと損です | あとで見返せる形にしてあります |
| LINEはこちら | 詳しい記事、各SNS、コミュニティ案内はプロフィールのリンクにまとめています |

案内の基本語彙は「置いておきます」「まとめています」「のぞいてみてください」「気になるところだけで大丈夫」。参加命令や限定煽りは使わない。

## 案内文の固定方針

```
Threads:
この投稿だけだと説明しきれない部分が多いので、詳しい根拠はNoteに置いておきます。

Note:
ここまで読んでくれてありがとうございます。

LINEオープンチャットもあります。
ゆるく情報交換する場所なので、気になるテーマがあればのぞいてみてください。
```

詳細書式は `references/line-oc-templates.md` 参照。

## セルフチェック（writer 出力前必須）

### 標準語徹底

- [ ] 関西弁の語尾「〜やで／〜ねん／〜やん／〜やろ／ほな／せやから／ほんま／めっちゃ／ええ感じ」が**一切**混入していないか
- [ ] AI っぽい抽象語（最適化／アプローチ／フレームワーク／ソリューション）が混入していないか
- [ ] 曖昧表現（ケースバイケース／一概には／個人差／人による）が混入していないか

### 案内文の温度感

- [ ] 「あなた」「皆様」「読者の方」「視聴者の皆さん」が案内文に混入していないか
- [ ] 「俺ら／俺たち」が案内文で前に出すぎていないか（本文では可、案内文では控える）
- [ ] 「置いておきます」「のぞいてみてください」系の柔らかい案内になっているか

### 外部誘導の安全性

- [ ] Threads に LINE 直リンクや LINE オープンチャット案内が混入していないか
- [ ] Note 末尾はプロフィールリンク / 公式リンク集への案内になっているか
- [ ] Note 末尾に医療相談・個別診断ではない旨が入っているか
