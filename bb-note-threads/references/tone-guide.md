# 文体・トーンガイド（低温の標準語ベース）

bb-note-threads 全体の口調・トーン指針。全媒体・全パートを標準語で運用する。Threads は特に、関西弁っぽい親しさ・語尾・勢いを落とした **低温の標準語 BB トーン**にする。

関連正本:

- ブランド前提: [brand-profile.md](./brand-profile.md)
- 専門用語翻訳: [domain-vocabulary.md](./domain-vocabulary.md)
- CTA / 外部導線: [cta-policy.md](./cta-policy.md)

## 基本方針

| 媒体 / パート | トーン | 役割 |
|---|---|---|
| Threads ツリー本体 | 低温の標準語・断定・体言止め可・数字で強く言う | 短文で言い切る |
| Threads 最終リプ | 標準語・温かい・ゆるい | Note案内 |
| Note 地の文 | 標準語・落ち着いた論証・ファクトで押す | 深掘り |
| Note 主張・体験談 | 標準語・断定・体言止め | 熱量を担う |
| Note 末尾の関連リンク案内 | 標準語・温かい・ゆるい | 公式 LINE OC への案内 |

## Threads の低温ルール（必須）

Threads は関西弁をゼロにするだけでなく、関西弁っぽく読める温度感も下げる。

| 対象 | OK | NG |
|---|---|---|
| 語尾 | 「〜だ」「〜になる」「〜していい」「〜ではない」 | 「〜やで」「〜やん」「〜ねん」「〜やろ」 |
| 主語 | 主語を省く / 「BBでは」 / 「この基準では」 | `俺ら` の連発、読者へ距離を詰める呼びかけ |
| 熱量 | 数字・比較・損失額で強く言う | 勢い、ノリ、親しさで押す |
| 問い | 1投稿1問まで。短く置く | 「〜ですよね？」「〜じゃないですか？」の連発 |
| 感情 | 怒りは事実の裏に置く | 叫ぶ、煽る、馴れ馴れしくする |

Threads 本体では `俺ら` / `俺たち` を原則使わない。ブランドの立場を明示する必要がある場合のみ、ツリー全体で1回までにする。案内文では完全に使わない。

## 標準語 BB トーンの基本フォーム

推奨:

- 断定: 「〜である」「〜だ」「〜になる」「〜していい」
- 体言止め: 「年間で数万円の差。」「これが現実。」
- 反語: 「これを知らずに飲み続ける選択肢があるのか」
- 名詞文: 「論文と現場の距離、平均10年。」
- 短い問い → 即断ち切る回答: 「正解は何か。事実だけで決める。」

禁止:

- 関西弁の語尾・温度: 「〜やで」「〜ねん」「〜やん」「〜やろ」「ほな」「せやから」「ほんま」「めっちゃ」「ええ感じ」
- AIっぽい抽象語: 「最適化」「アプローチ」「フレームワーク」「ソリューション」「コミットメント」
- 曖昧表現: 「ケースバイケース」「一概には」「人によりますが」「個人差があります」
- 客体化: 「あなた」「皆様」「読者の方」「視聴者の皆さん」
- 過剰な疑問形・連投: 「〜でしょうか？」「〜ですよね？」を1投稿に2つ以上
- 自虐 / へりくだり: 「未熟ですが」「私たちごときが」

## 「俺ら／俺たち」の使い分け

- Threads 親 + 本体リプ: 原則使わない。必要な場合のみツリー全体で1回まで。
- Note 地の文: BBの主体性を示すため使用可。ただし連発せず、章内1回程度に抑える。
- Threads 最終リプ / Note 関連リンク案内: 完全に封印。

## 温かい案内トーン

案内文は「売り込まず、置いておく」書き方を徹底する。具体テンプレは [cta-policy.md](./cta-policy.md) を使う。

| 強い誘導 | 温かい案内 |
|---|---|
| 今すぐ参加してください | 気になるテーマがあればのぞいてみてください |
| 全員入ってください | 気になるところだけ読んでもらえれば大丈夫です |
| 参加しないと損です | あとで見返せる形にしてあります |
| LINEはこちら | 詳しい記事、各SNS、コミュニティ案内はプロフィールのリンクにまとめています |
