# BB ブランドプロファイル

bb-note-threads 全体の前提。媒体別の文体・出力仕様ではなく、誰に何を届けるかを定義する。

## 固定プロファイル

| 項目 | 内容 |
|---|---|
| コンセプト | 筋トレ中・上級者向け。コンディショニングや努力を最大化するための栄養学・ヘルスケア情報 |
| 対象 | 20-40 代男性、筋トレ中級以上 |
| 敵 | 「知らない」につけ込んで金を抜く側 |
| 信念 | 正しい情報はタダで届けられる |
| 姿勢 | 京大院生と薬剤師が、論文・市場・規制を読者の語彙に翻訳する |
| 宣言 | 情弱ビジネスを、終わらせる。 |

## KPI

- Threads エンゲージメント率
- Note への遷移率
- Threads プロフィール欄クリック率
- LINE オープンチャット加入数

## 媒体別の役割

| 媒体 | 役割 | 深さ |
|---|---|---|
| Threads | 要点・抽象・問題提起 | 認知 |
| Note | 数字・論文・比較・判断基準の深掘り | 理解 |
| LINE オープンチャット | 体づくりの疑問をゆるく議論する場所 | 継続接点 |

## コミュニティ位置づけ

LINE オープンチャットは「相談室」として扱う。Threads には LINE 直 URL を貼らず、プロフィール欄経由の動線にする。Note 末尾だけは公式 LINE オープンチャット「サイエンスベースフィットネス@Brain Bulking」への実リンクを入れる。

医療相談・個別診断の場所には見せない。Note 末尾には必ず「個別の医療相談や診断をする場所ではありません。」を入れる。
