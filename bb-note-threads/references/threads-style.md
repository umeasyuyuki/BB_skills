# Threads 投稿生成ルール（ツリー構成版）

Phase 2 の `threads-writer` エージェントが従うルール。

## 文体トーン（★必読）

Threads 投稿は **標準語 BB トーン**で書く。詳細ルール・OK/NG 表現は [tone-guide.md](./tone-guide.md) 参照。旧仕様の関西弁レベル 2 は廃止。

要点:
- 標準語・断定・体言止めを基調に、思想を叫ぶ BB トーンで貫く
- BB の「ファクトで殴る」「情熱が見える怒り」は事実と数字で表現する
- 関西弁の語尾（「〜やで／〜ねん／ほな／せやから／めっちゃ／ほんま」等）は**全文 NG**
- 最終リプは別レイヤー（温かく、ゆるい Note 案内）— 詳細は [line-oc-templates.md](./line-oc-templates.md)

## Threads の特性

- Meta のプラットフォーム、ユーザー層は 20-40 代のミレニアル / Z 世代寄り
- 会話・対話的なトーンが好まれる（X の「論破」文化とは違う）
- 「保存」「シェア」より「コメント」「いいね」が伸びやすい
- リンク投稿は表示優先度が下がる傾向 → URL は最終リプに集約
- **ツリー構成（親 → リプ）でクリック率と滞在時間を伸ばす設計**

## ツリー構成の前提（★必須）

1 投稿で完結させない。**親ポスト + リプライ複数** のツリー構造で配信する。

### 設計原則

| 原則 | 内容 |
|---|---|
| **誰向け宣言** | 親ポストの 1 行目で対象者を明示する（「〜したい人が」「〜キロ痩せて」等） |
| **言い切らない** | 親ポスト末尾と本体最終リプの直前は途中で切り、続きが気になる引きを作る |
| **読みやすさ** | 箇条書き or 2-3 行で空白を入れる |
| **Note案内は最終** | Note URL は **必ず最終単独リプ** に置き、本体ポストには入れない |
| **本体は完結** | 本体最終リプは「結論を言い切る」。最終リプは独立した Note 案内 |

### 各ポストの字数

- **本体ポスト（親 + 本体リプ）**: 200-300 字を厳守
- **Note案内リプ**: 100-180 字
- 短すぎ（< 150 字）は内容薄く見える
- 本体ポストは長すぎ（> 320 字）と折りたたまれる可能性

| 型 | 親 | 本体リプ | Note案内リプ | 合計 |

| **対比型** | 1 | 2 | 1 | 4 ポスト |

### 親ポスト

```

・〜
・〜
・〜
・〜
・〜

```

★親末尾は「1 番効くのは、」「1 番のおすすめは、」「1 番外せないのは、」で切る。

### 本体リプ

```
1 番効くのは「〜」

〜の論文（著者, 年）でも結果が出ている。

```

★本体最終リプは結論を言い切る。「〜だ」「〜になる」「体言止め」で締める。

## Note案内リプ共通フォーマット（最終ポスト）

Note URL プレースホルダだけを置く。Threads では LINE オープンチャット、プロフィールリンク、公式リンク集には触れない。**字数目安は 100-180 字**。

```
この投稿だけだと説明しきれない部分が多いので、詳しい根拠はNoteに置いておきます。

気になるところだけ読んでもらえれば大丈夫です。
成分表や選び方を、あとで見返せる形にしてあります。

📝 詳しい根拠と数値はこちら
【★Note URL を貼る★】
```

詳細は [line-oc-templates.md](./line-oc-templates.md) 参照。

## 共通の書き方原則

| ルール | OK | NG |
|---|---|---|
| 1 行目（親ポスト） | 誰向けか・状況を明示 | 抽象的なフック |
| 末尾の引き | 「1 番のおすすめは、」「気をつけたのは、」で切る | 「以上です」「ぜひ参考に」 |
| 段落の区切り | 2-3 行で改行、空白行を入れる | 5 行以上の塊 |
| 語尾の揃え | 「〜だ」「〜になる」「体言止め」をミックス | 「〜です」連続、関西弁の語尾 |
| 装飾記号 | ❌⭕️、・、↓、📝、絵文字最小限 | 過剰な絵文字、`**` 等の Markdown |
| 数字 | 必ず 1 つ以上の数値 | 抽象論のみ |
| 一次情報 | 体験・主観を 1 行入れる | 客観論だけ |

## 禁止表現

### 関西弁全般（旧仕様廃止に伴い全面 NG）

- 語尾: 「〜やで」「〜ねん」「〜やん」「〜やろ」「〜まんねん」「〜やんけ」
- 接続: 「ほな」「せやから」「せやけど」
- 副詞: 「めっちゃ」「ほんま」「えらい」「ちゃう」
- 表現: 「ええ感じ」「知らんけど」「あかん」

### AI っぽさ排除

- 「プロトコル」「最適化」「アプローチ」「フレームワーク」「ソリューション」
- 「ケースバイケース」「一概には」「個人差があります」「人によります」
- 「〇〇が大切です」「〇〇を意識しましょう」
- 同じ語尾の 3 回連続
- 地図・羅針盤・DNA 等の使い古された比喩
- `**強調**` や `## 見出し` などの Markdown 記号

### 誘導文限定の追加 NG

- 「あなた」「皆様」「読者の方」「視聴者の皆さん」など読者を客体化する呼び方
- 「俺ら」「俺たち」（誘導文では封印、本文では可）

## サンプル完成形（対比型、debunk カテゴリ、標準語 BB トーン）

### 親ポスト（246 字）

```
筋トレ後の打ち上げで悩んでいる人へ。

「筋トレした日に酒を飲むと全部無駄」
これ、半分は嘘で半分は本当。

❌ 削れる飲み方
・トレ後すぐビール 3 杯
・純アルコール 40g 超
・就寝直前まで飲む
・空腹で飲む

⭕️ 削れない飲み方は、
```

### 本体リプ 1（251 字）

```
⭕️ 削れない飲み方

・トレ後 4 時間あけてから
・純アルコール 20g 以下（中瓶 1 本）
・糖質低めのウィスキーかジン
・就寝 3 時間前に終える

これさえ守れば、Parr et al. の論文で
合成阻害がほぼゼロになると出ている。

その中で 1 番効くのが、
```

### 本体リプ 2（254 字）

```
1 番効くのは「トレ後 4 時間ルール」

理由は、筋原線維タンパク質合成のピークが
トレ直後 1-3 時間に来るから。
ここをアルコールで潰すと、24% 削れる。

逆に 4 時間後ならピーク通過済み。
影響は 5% 以下に収まる。

完全禁酒は無理でいい。
時間だけ、ちゃんと設計する。
```
