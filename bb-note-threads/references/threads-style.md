# Threads 投稿生成ルール（ツリー構成版）

Phase 2 の `threads-writer` エージェントが従うルール。

## 関西弁兄貴ノリ（★必読）

Threads 投稿は **関西弁レベル 2 + お兄ちゃんノリのミックス** で書く。詳細ルール・OK/NG 表現・サンプルは [kansai-tone.md](./kansai-tone.md) を参照。

要点:
- 動詞・接続詞・語尾を関西弁化（「〜やねん」「〜なんやで」「〜やんな」「ほな」「せやから」等）
- お兄ちゃんが教えてくれる感覚で、フィットネスの科学を楽しく届ける
- 怒りで殴るスタンスは封印（「やめろ」→「やめとこ」「もったいないで」）
- 空想科学読本ノリ（比喩・桁スケール・仮想思考）を散りばめる
- **体言止めは禁止**（語り口調で書く）
- L1（テーマ連動フック）は関西弁兄貴ノリ、**L2-L4 固定文は標準語のまま維持**
- NG: 「〜まんねん」「〜やんけ」「ええ感じ」「知らんけど」「俺らはこれを許せない」等

## Threads の特性

- Meta のプラットフォーム、ユーザー層は 20-40 代のミレニアル / Z 世代寄り
- 会話・対話的なトーンが好まれる（X の「論破」文化とは違う）
- 「保存」「シェア」より「コメント」「いいね」が伸びやすい
- リンク投稿は表示優先度が下がる傾向 → URL は最終リプに集約
- **ツリー構成（親 → リプ）でクリック率と滞在時間を伸ばす設計**

## ツリー構成の前提（★必須）

1 投稿で完結させない。**親ポスト + リプライ複数** のツリー構造で配信する。

### 設計原則

| 原則 | 内容 |
|---|---|
| **誰向け宣言** | 親ポストの 1 行目で対象者を明示する（「〜したい人が」「〜キロ痩せて」等） |
| **言い切らない** | 親ポスト末尾と本体最終リプの直前は途中で切り、続きが気になる引きを作る |
| **読みやすさ** | 箇条書き or 2-3 行で空白を入れる。1 ポスト 200-300 字を厳守 |
| **誘導は最終** | LINE OC URL と Note URL は **必ず最終単独リプ** に併記、本体ポストには入れない |
| **本体は完結** | 本体最終リプは「結論を言い切る」。誘導リプは独立した CTA |

### 各ポストの字数

**全ポスト 200-300 字**を厳守（親ポスト・本体リプ・誘導リプすべて）。
- 短すぎ（< 150 字）は内容薄く見える
- 長すぎ（> 320 字）は折りたたまれる可能性

## 型 1: ⚪選系（3 ポスト構成）

### 親ポスト

```
[誰向け宣言]
〜したい人が〜するべき〜⚪選

・〜
・〜
・〜
・〜
・〜

この中でも 1 番ええのは、
```

★親末尾は「1 番ええのは、」「1 番のおすすめは、」「1 番効くのは、」で切る（関西弁版）。

### 本体リプ

```
1 番ええのは「〜」

理由はな、〜やから〜できるねん。

〜っていう具体的な根拠もある。
〜の場合は特に効くで。
```

★本体最終リプは結論を関西弁で言い切る。「〜やで」「〜やねん」で締める。

## 共通の書き方原則

| ルール | OK | NG |
|---|---|---|
| 1 行目（親ポスト） | 誰向けか・状況を明示 | 抽象的なフック |
| 末尾の引き | 「1 番のおすすめは、」「気をつけたのが、」で切る | 「以上です」「ぜひ参考に」 |
| 段落の区切り | 2-3 行で改行、空白行を入れる | 5 行以上の塊 |
| 語尾の揃え | 「〜だ」「〜なる」「体言止め」をミックス | 「〜です」連続 |
| 装飾記号 | ❌⭕️、・、↓、📝、絵文字最小限 | 過剰な絵文字、`**` 等の Markdown |
| 数字 | 必ず 1 つ以上の数値 | 抽象論のみ |
| 一次情報 | 体験・主観を 1 行入れる | 客観論だけ |

## 禁止表現（AI っぽさ排除）

- 「プロトコル」「最適化」「アプローチ」
- 「ケースバイケース」「一概には」「個人差があります」
- 「〇〇が大切です」「〇〇を意識しましょう」
- 同じ語尾の 3 回連続
- 地図・羅針盤・DNA 等の使い古された比喩
- `**強調**` や `## 見出し` などの Markdown 記号
