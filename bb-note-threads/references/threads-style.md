# Threads 投稿生成ルール（ツリー構成版）

Phase 2 の `threads-writer` エージェントが従う共通ルール。8型テンプレートは [threads-patterns.md](./threads-patterns.md) に分離する。

## 文体トーン

Threads 投稿は **低温の標準語 BB トーン**で書く。

必読:

- 共通トーン: [tone-guide.md](./tone-guide.md)
- 専門用語翻訳: [domain-vocabulary.md](./domain-vocabulary.md)
- 型テンプレート: [threads-patterns.md](./threads-patterns.md)
- CTA / 最終リプ: [cta-policy.md](./cta-policy.md)
- 出力形式: [output-spec.md](./output-spec.md)

要点:

- 低温の標準語・断定・体言止めを基調に、事実と数字で強く言う。
- BBの怒りや思想は、勢いではなく比較・損失額・規制・論文の差で表現する。
- 関西弁の語尾、関西弁っぽい親しさ、馴れ馴れしい勢いは全文NG。
- `俺ら` / `俺たち` は原則使わない。必要な場合でもツリー全体で1回まで。
- 学術略称・カタカナ専門語は [domain-vocabulary.md](./domain-vocabulary.md) に従って読者の語彙に翻訳する。
- PubMed ID・論文著者名は Threads では一切出さない。

## Threads の特性

- Meta のプラットフォーム、ユーザー層は 20-40代のミレニアル / Z世代寄り。
- 会話・対話的なトーンが好まれる。Xの論破文化とは違う。
- 「保存」「シェア」より「コメント」「いいね」が伸びやすい。
- リンク投稿は表示優先度が下がる傾向があるため、URLは最終リプに集約する。
- ツリー構成（親 → リプ）でクリック率と滞在時間を伸ばす。

## ツリー構成の前提

1投稿で完結させない。親ポスト + リプライ複数のツリー構造で配信する。

| 原則 | 内容 |
|---|---|
| 誰向け宣言 | 親ポストの1行目で対象者を明示する |
| 言い切らない | 親ポスト末尾と本体最終リプ手前は途中で切る |
| 読みやすさ | 箇条書き or 2-3行で空白を入れる |
| 本体は完結 | 本体最終リプは結論を言い切る |
| 最終リプ | [cta-policy.md](./cta-policy.md) の D-2 二段構成を使う |

## 各ポストの字数

- 本体ポスト（親 + 本体リプ）: 200-300字を厳守
- 最終リプ（Note案内 + LINE OC匂わせ）: 240-300字
- 短すぎ（150字未満）は内容が薄く見える
- 本体ポストが長すぎる（320字超）と折りたたまれる可能性がある

## 共通の書き方原則

| ルール | OK | NG |
|---|---|---|
| 1行目 | 誰向けか・状況を明示 | 抽象的なフック |
| 末尾の引き | 「1番のおすすめは、」「気をつけたのは、」で切る | 「以上です」「ぜひ参考に」 |
| 段落 | 2-3行で改行、空白行を入れる | 5行以上の塊 |
| 語尾 | 「〜だ」「〜になる」「体言止め」をミックス | 「〜です」連続、関西弁の語尾、馴れ馴れしい語尾 |
| 装飾 | ❌⭕️、・、↓、📝、絵文字最小限 | 過剰な絵文字、Markdown記号 |
| 数字 | 必ず1つ以上の数値、単位付き | 抽象論のみ |
| 専門用語 | 日常語化、または初出で日常語訳併記 | ACSM、mEq/L、mTORC1等を素のまま |
| 主語 | 主語を省く / 「BBでは」 | `俺ら` / `俺たち` の連発 |

## 禁止表現

### 関西弁全般

- 語尾: 「〜やで」「〜ねん」「〜やん」「〜やろ」「〜まんねん」「〜やんけ」
- 接続: 「ほな」「せやから」「せやけど」
- 副詞: 「めっちゃ」「ほんま」「えらい」「ちゃう」
- 表現: 「ええ感じ」「知らんけど」「あかん」

### AIっぽさ

- 「プロトコル」「最適化」「アプローチ」「フレームワーク」「ソリューション」
- 「ケースバイケース」「一概には」「個人差があります」「人によります」
- 「〇〇が大切です」「〇〇を意識しましょう」
- 同じ語尾の3回連続
- 地図・羅針盤・DNA等の使い古された比喩
- `**強調**` や `## 見出し` などのMarkdown記号

### Threads 本体の低温化NG

- `俺ら` / `俺たち` の連発（使う場合もツリー全体で1回まで）
- 「ぶっちゃけ」「知らないと損」「全員これ」など勢いで距離を詰める表現
- 関西弁ではないがノリが強い語尾（「〜っしょ」「〜じゃん」「〜だよね」）
