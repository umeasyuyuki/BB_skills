# セルフチェック・品質ゲート

writer エージェントが Phase 2 出力前に必ず実行する 12 項目のセルフチェックと、Phase 3 の薬機法ゲート仕様。

## Phase 2 セルフチェック（12 項目）

threads-writer / note-writer は出力前に以下を全て確認する。1 つでも未達なら出力を保留し、修正してから提出する。

### A. 文字数・構造

- [ ] **A-1** 各ポストの字数が範囲内か（Threads 各ポスト 200-300 字 / Note 全体 2500-3500 字）
- [ ] **A-2** 構造が揃っているか
  - Threads: 親 + 本体リプ + 誘導リプ（型ごとのツリー深さ：⚪選系・ランキング系 = 3 / 体験談型・対比型 = 4）
  - Note: 6 ブロック（導入 → 結論 → 本論 3-5 → 体験談 → まとめ → 誘導）
- [ ] **A-2-Threads** Threads 親ポストの 1 行目で対象者・状況が明示されているか
- [ ] **A-2-Threads-2** Threads 親ポスト末尾が「言い切らない引き」（「1 番のおすすめは、」「気をつけたのが、」「⭕️ 続く人は、」等）で切れているか
- [ ] **A-2-Threads-3** 本体リプの末尾は引きを作るか結論を言い切るか、型ルール通りか

### B. LINE OC 誘導の正確性

- [ ] **B-1** L1（テーマ連動フック）が記事テーマと連動しており、参考プールのコピペになっていないか
- [ ] **B-2** L2 ポジショニング固定文が一字一句一致しているか
  - Threads: 「京大院生と薬剤師が、日本最先端を本気で目指す、完全無料のフィットネス × ヘルスケアコミュニティ。」
  - Note: 「京大院生と薬剤師が、日本最先端を本気で目指す、完全無料のフィットネス × ヘルスケア LINE コミュニティ。」
- [ ] **B-3** L3 変化訴求固定文が一字一句一致しているか
  - Threads（圧縮版）: 「成分表を見て、体に必要なものを判断できるように。」
  - Note: 「読んでいるだけで、成分表を見て体に必要なものを自分で判断できるレベルになる。」
- [ ] **B-4** LINE OC URL が完成形（`https://line.me/ti/g2/lmmjCh0V39BIgClQxQmsm4Hb-G8Hb7VFsnVOuw`）で直書きされているか
- [ ] **B-5** チャット名「サイエンスベースフィットネス@Brain Bulking」が末尾に明記されているか

### C. Note URL プレースホルダ（Threads のみ）

- [ ] **C-1** Threads **誘導リプ** に `【★Note URL を貼る★】` プレースホルダが含まれているか（本体ポストには絶対入れない / Note 出力時はこの項目を「N/A」とする）
- [ ] **C-2** 本体ポスト（親 + 本体リプ）に LINE OC URL が混入していないか（誘導リプ専用）

### D. 文体・口調

- [ ] **D-1** BB 口調（情熱が見える怒り、断定、体言止め可）になっているか
- [ ] **D-2** AI っぽい曖昧表現が混入していないか
  - 禁止: 「ケースバイケース」「一概には」「個人差があります」「最適化」「アプローチ」「プロトコル」
- [ ] **D-3** 同じ語尾の 3 回連続が無いか
- [ ] **D-4** Markdown 記号（`**`、`##`）が本文中に残っていないか（Note の見出し H2 は OK、Threads は NG）

### E. 関西弁トーン（★必須）

- [ ] **E-1** 関西弁レベル 2（バランス型）になっているか（強すぎず弱すぎず）
- [ ] **E-2** 関西弁 NG 表現が混入していないか
  - 禁止: 「〜まんねん」「〜でんねん」「〜やんけ」「ええ感じ」「知らんけど」「個人差あるけどな」「ええんちゃう？」
- [ ] **E-3** Note の場合、地の文（標準語）と主張・ツッコミ・体験談（関西弁）の使い分けが適切か
- [ ] **E-4** 論文引用・数値解説部分が標準語を維持しているか（信頼性確保）
- [ ] **E-5** L2-L4 固定文が**標準語のまま**維持されているか（関西弁化していないか）
- [ ] **E-6** L1 が関西弁レベル 2 で記事テーマと連動しているか
- [ ] **E-7** キャラ作り感・芸人物真似感が出ていないか（自然な関西出身者の文体）

## Phase 3 薬機法ゲート

`tiktok-fit-compliance-check` を呼び出し、Threads と Note の両本文を並列でチェックする。

### 判定基準

| 判定 | 基準 |
|---|---|
| **Green** | 違反なし、Phase 4 へ進行 |
| **Yellow** | グレーゾーン表現あり、ユーザーに最終判断を委ねる |
| **Red** | 明確な薬機法違反あり、writer に修正依頼 |

### Red 判定時のリトライ手順

```
リトライ 1 回目:
  → writer に違反箇所と修正提案を渡し、修正版を生成依頼
  → 再度 compliance-check を実行

リトライ 2 回目:
  → 同上
  → 再度 compliance-check を実行

3 回目以降:
  → ユーザーに手動修正を依頼（中断）
```

### 修正依頼テンプレ

```
以下の表現が薬機法上 Red 判定でした:

違反箇所: "{違反テキスト}"
違反タイプ: {効能効果の暗示 / 治療効果の標榜 / 等}
重大度: {高 / 中 / 低}
修正提案: "{言い換え案}"

該当箇所を修正し、表現を弱めるか、エビデンス引用形式に変更してください。
全体の論旨は維持すること。修正版を出力してください。
```

### Yellow 判定時の挙動

```
ユーザーに以下を提示:
  - 違反箇所
  - グレーゾーンの理由
  - そのまま投稿するリスク（重大度: 低 / 中 / 高）
  - 修正案（あれば）

ユーザーの判断:
  - "そのまま" → Phase 4 へ
  - "修正" → writer に修正依頼（Red と同じフロー）
```

## サプリ・栄養テーマでの追加チェック

ingredient カテゴリの場合、以下を追加でチェックする:

- [ ] 効能効果の暗示（「○○が効く」「○○を治す」等）が無いか
- [ ] 「医薬品的」表現が無いか
- [ ] 安全性に関する誤解を生む表現が無いか
- [ ] 推奨摂取量を超える量を勧めていないか
- [ ] 薬剤師チームの監修済みであることが文中に示されているか（強制ではない、推奨）

## 失敗時のエラーログ

セルフチェック未達 / 薬機法 Red 連続 3 回時、以下のログを `output/<timestamp>/error.log` に保存する:

```
timestamp: 2026-04-28T13:45:00Z
phase: 2 (writer) / 3 (compliance)
agent: threads-writer / note-writer
fail_type: selfcheck_incomplete / compliance_red_3times
fail_items: ["B-2", "D-2"]
retry_count: 3
last_output_excerpt: "..."
```

ユーザーが原因を分析し、後続の改善に使えるようにする。
