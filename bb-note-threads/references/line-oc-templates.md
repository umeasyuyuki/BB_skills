# 関連リンク・コミュニティ案内テンプレ

Threads 投稿と Note 記事の末尾に入れる案内文の正本。旧仕様の LINE 直リンク誘導は廃止し、Threads は Note への自然な案内、Note はプロフィールリンク / 公式リンク集への温かい案内に統一する。

## 固定プレースホルダ

| 用途 | プレースホルダ |
|---|---|
| Note 記事 URL | `【★Note URL を貼る★】` |
| プロフィールリンク / 公式リンク集 URL | `【★プロフィールリンク / 公式リンク集 URL を貼る★】` |

## 設計思想

- Threads では LINE オープンチャットに直接誘導しない
- Threads の最終リプは、投稿で省いた根拠や数字を Note に置いたことだけを伝える
- Note 末尾では、公式情報・SNS・コミュニティ案内をまとめたプロフィールリンクへ案内する
- 誘導文は「入ってください」ではなく、「置いておきます」「気になるところだけで大丈夫」「のぞいてみてください」の温度感にする
- 健康・栄養・ヘルスケア領域では、医療相談や個別診断ではないことを明記する

## Threads 最終リプ

Threads の最終リプは **Note 案内のみ**にする。LINE、オープンチャット、プロフィールリンク、公式リンク集、短縮 URL は書かない。

文字数目安: 100〜180 字。

### 標準テンプレ

```
この投稿だけだと説明しきれない部分が多いので、詳しい根拠はNoteに置いておきます。

気になるところだけ読んでもらえれば大丈夫です。
成分表や選び方を、あとで見返せる形にしてあります。

📝 詳しい解説はこちら
【★Note URL を貼る★】
```

### 数値・根拠強めテンプレ

```
ここではかなり端折ったので、根拠や数字はNoteにまとめました。

気になったところだけ、あとで拾い読みできるように置いておきます。
感覚ではなく、数字で見たい人向けです。

📝 詳しい解説はこちら
【★Note URL を貼る★】
```

### 比較記事テンプレ

```
細かい比較表と根拠はNoteに置いておきます。

今すぐ全部読まなくても大丈夫です。
買う前、選ぶ前、あとで迷ったときに見返せる形にしてあります。

📝 詳しい解説はこちら
【★Note URL を貼る★】
```

## Note 末尾構造

Note の末尾は **関連リンク** セクションにする。LINE オープンチャットは選択肢の 1 つとして控えめに触れ、直接 URL は貼らない。リンク先はプロフィールリンク / 公式リンク集 URL にまとめる。

見出しは `## 関連リンク` で固定。

### 標準テンプレ

```
────────

## 関連リンク

ここまで読んでくれてありがとうございます。

BBでは、フィットネス・栄養・ヘルスケアの話を、NoteやSNSで少しずつ整理しています。
詳しい記事、各SNS、コミュニティ案内はプロフィールのリンクにまとめています。

LINEオープンチャットもあります。
ゆるく情報交換する場所なので、気になるテーマがあればのぞいてみてください。

※ 個別の医療相談や診断をする場所ではありません。

【★プロフィールリンク / 公式リンク集 URL を貼る★】
```

### 少し短め

```
────────

## 関連リンク

ここまで読んでくれてありがとうございます。

詳しい記事、各SNS、コミュニティ案内はプロフィールのリンクにまとめています。
LINEオープンチャットもあるので、気になるテーマがあればゆるくのぞいてみてください。

※ 個別の医療相談や診断をする場所ではありません。

【★プロフィールリンク / 公式リンク集 URL を貼る★】
```

## 禁止事項

### Threads 全体で禁止

- `line.me` URL
- `LINEオープンチャット` / `LINE オープンチャット`
- `プロフィールのリンクから` など、LINE 以外も含む外部導線の重ねがけ
- `完全無料`
- `日本最先端`
- `入っていることがステータス`
- `読んでいるだけで判断できる`
- `今すぐ参加`
- `👇`

### Note 末尾で禁止

- LINE の直接 URL
- 強い参加命令
- 過剰な限定感
- 効果保証に見える表現
- 医療相談や個別診断を受けられるように見える表現
