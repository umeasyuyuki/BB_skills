## L1（テーマ連動フック）の生成ルール

writer エージェントが Phase 1 のリサーチ結果と本文を踏まえ、記事ごとに**新規生成**する。

### 生成プロンプト方針

```
記事のテーマと「最新トレンドを知らないと損する」を
1〜2 行で結ぶ。

口調: BB 口調（情熱が見える怒り、断定、体言止め可、AI っぽさゼロ）
文字数: Threads 誘導リプ用 80-120 字（200-300 字リプ内で L1-L4 全部入れるため圧縮）/ Note 用 60-100 字（2-3 行に肉付け）

NG:
- 過去の記事と同じフレーズの使い回し
- 「ケースバイケース」「一概には」等の曖昧表現
- 「あなた」呼び（俺ら / 俺たち目線で）
- AI っぽい「最適化」「アプローチ」
```

### カテゴリ別 L1 参考プール（コピペ NG、毎回新規生成のお手本、関西弁兄貴ノリ）

L1 は **関西弁兄貴ノリ** で書く。怒りで殴らない、お兄ちゃんが教えてくれる感じで。L2-L4 は標準語のまま固定。Note 用は Threads 用を 2-3 行に肉付けする。

#### サプリ・栄養（ingredient 系）

Threads 用:
```
プロテイン、来月もまた上がるって知ってた？
情報 1 ヶ月遅れるだけで、年間で数千円飛んでくねん。
ちょっと損するの、もったいないやんな。
```

Note 用（2-3 行に肉付け）:
```
プロテイン、来月もまた上がるんやで。再来月も上がる。
情報を 1 ヶ月遅れで掴むだけで、年間で数千円が静かに消えてく。
これ知っとくだけで、買い時のタイミングがちょっと変わるねん。
```

#### 筋トレ理論（debunk / discovery 系）

Threads 用:
```
2020 年の筋トレ常識、もう半分は古いって知ってた？
雑誌で見る頃には、研究はもう次の地点いってんねん。
```

Note 用:
```
2020 年に常識やったトレーニング理論、もう半分は古いんよね。
雑誌や YouTube で見る頃には、研究はもう次の地点いってる。
今の知識でアップデートしとくと、毎回のトレが地味に効率化するで。
```

#### ヘルスケア・医学（discovery / debunk 系）

Threads 用:
```
論文が現場に届くまで、平均 10 年かかるんやで。
その 10 年のラグで、コンディションは確実に変わる。
```

Note 用:
```
論文が出てから、現場のジムやクリニックに届くまで平均 10 年。
その 10 年の差が、コンディションの差、寿命の差、QOL の差になってくねん。
俺らはその 10 年を埋める仕事してると思ってる。
```

#### 成分・原材料（ingredient 系）

Threads 用:
```
成分表、ちゃんと読めるとサプリ代がだいぶ変わるんやで。
読まずに買ってる人、ちょっと損してるかも。
```

Note 用:
```
サプリの成分表、ぱっと見て中身が分かる人って意外と少ないんよね。
「人気やから」「安いから」で選んで、気づけば毎月数千円、
効きが弱いものに払ってる、みたいなことが起きやすい。
```

#### ビジネス・コスパ（compare / discovery 系）

Threads 用:
```
AI に聞ける時代やけど、信頼できる答えはまだ AI の中にない。
論文・現場の生きた情報は、誰かが翻訳せな届かへんねん。
```

Note 用:
```
AI に何でも聞ける時代になった。
でも、ホンマに信頼できる答えは、まだ AI の中にないんよね。
論文・現場・規制の生きた情報は、誰かが翻訳せな届かへんねん。
俺らはその翻訳係を、毎朝やってる。
```

## URL とチャット名の運用ルール

1. **完成形 URL を直書きする**。プレースホルダ（`【★LINE URL を貼る★】` 等）は使わない。
2. **チャット名「サイエンスベースフィットネス@Brain Bulking」を必ず明記する**。URL だけでは何のコミュニティか伝わらない。
3. **TikTok カルーセルには絶対に入れない**。テキスト媒体（Threads / Note）のみに入れる。
4. **URL は文末に 1 本だけ**。Threads は外部リンクの表示優先度が下がる傾向 → 複数 URL は避ける。
