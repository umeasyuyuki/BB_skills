# 専門用語の翻訳辞書

BB の読者は筋トレ中級〜上級者だが、運動科学・栄養学の学術略称やカタカナ専門語を知っている層は少ない。論文と数字で強く言う思想は維持しつつ、用語は読者の語彙へ翻訳する。

## 原則

| 対象 | 扱い | 例 |
|---|---|---|
| 数値・単位（%、mg、g、kcal、円、年） | 無翻訳で残す | `糖質6.2%` / `Na 245mg` / `年7.8万円` / `60分以内` |
| 学術略称・英字団体名 | 初出のみ日常語で言い換え、以降は日常語で通す | `ACSM` → `世界のスポーツ医学団体（ACSM）` 初出のみ。本文は「運動科学の国際基準」「世界のガイドライン」 |
| カタカナ学術語 | 日常語に翻訳して書く。原語は脚注 / 参考文献にのみ残す | `アイソトニック` → `体液と同じ濃さ` |
| 生化学略称 | 機能で言い換える。原語は本文では使わない | `mTORC1` → `筋肉が作られるスイッチ` |
| 単位変換 | 本文では mg/L、g/L 等の馴染みある単位に変換。原単位は脚注にのみ残す | `21 mEq/L` → 本文は `Na 約500mg/L` |
| PubMed ID / 論文著者名 | Note の脚注のみで使用。Threads では一切出さない | Threads では「研究で参考にされる目安量」「世界のガイドライン」 |

## 翻訳辞書

| 専門語 | 標準語訳 | 文脈例 |
|---|---|---|
| ACSM | 世界のスポーツ医学団体 / 運動科学の国際基準 | 「世界のガイドラインでは〜と推奨されている」 |
| 推奨域 / レンジ | 推奨される範囲 | 「世界のガイドラインが推奨する範囲のど真ん中」 |
| アイソトニック | 体液と同じ濃さ | 「ポカリは体液と同じ濃さで作られている」 |
| ハイポトニック | 体液より薄い | 「アクエリは体液よりやや薄い側」 |
| 浸透圧 | 濃さ（必要時のみ「液体の濃さ」と補足） | 「液体の濃さの単位で見ると〜」 |
| 経口補水液 | 脱水時用の医療向け飲料 | 「OS-1 は脱水時用の医療向け飲料」 |
| MPS / 筋タンパク合成 | 筋肉の合成 | 「筋肉の合成が 24% 落ちた」 |
| mTORC1 | 筋肉が作られるスイッチ | 「筋肉が作られるスイッチが押されにくくなる」 |
| グリコーゲン | 筋肉のエネルギータンク | 「筋肉のエネルギータンクが空になる」 |
| インスリン応答 | 血糖が上がったときの体の反応 | 「血糖が上がる反応で〜」 |
| EAA / BCAA | 必須アミノ酸 / 必須アミノ酸の一種（BCAA） | 「BCAA（必須アミノ酸の一種）」 |
| WPI / WPC | ホエイプロテイン（製法違い） | 「ホエイプロテイン」「精製度の高いホエイ」 |
| HRV | 自律神経のばらつき | 「自律神経のばらつきで見ると〜」 |
| 生体利用率 | 体に届く割合 | 「飲んだうちどれだけ体に届くか」 |
| 浸透圧勾配 | 濃さの差 | 「濃さの差で水が引き寄せられる」 |
| 純アルコール | 純粋なアルコール量 | 「純粋なアルコール量で 20g 以下」 |

## 翻訳が不要な数値表現

- 単位付き数値: `糖質 6.2%`、`Na 245mg`、`125 kcal`、`70kg の男性`、`月 6500 円`、`年 7.8 万円`、`24% 削れる`、`4-8% の糖質`
- 時間表現: `60 分以内`、`90 分超`、`4 時間ルール`、`3 ヶ月`
- 商品名: `ポカリ`、`アクエリ`、`OS-1`、`プロテイン`

## NG パターン

- `ACSM Position Stand` のような英語論文タイトルを本文に出す → 「世界のスポーツ医学団体のガイドライン」
- `mEq/L` `mOsm/L` のような単位を本文に出す → mg/L か「液体の濃さ」に変換
- `Parr et al. (2014) の研究で MPS が阻害される` → 「ある研究では筋肉の合成が抑えられる結果が出ている。詳細は脚注」
- 専門語を翻訳せず注釈なしで通す → 初出で日常語訳を併記、または最初から日常語化
