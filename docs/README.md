# BB Management Docs

この `docs/` は、BB_skills を単なる skill 集から Brain Bulking 全体の管理基盤へ広げるための運用ドキュメント置き場。

## ディレクトリ

| Path | 役割 |
|---|---|
| `strategy/` | BB の戦略、ポジショニング、SNS方針 |
| `progress/` | 週次進捗、意思決定、ブロッカー、次アクション |
| `monetization/` | BB Checker、アフィリエイト、コミュニティ、案件設計 |
| `system/` | skill、Notion、自動化、レンダリング、将来アプリの設計 |
| `research/` | 調査運用、トレンド調査、レポート保管ルール |

## 現在の運用原則

1. 投稿制作の入口は `contents-fullmake` に集約する。
2. 事業・マネタイズ・戦略壁打ちの入口は `bb-business-strategist` に集約する。
3. 直接使わない skill は原則 archive し、必要なら component として残す。
4. BB 戦略の詳細な原本は `/Users/asyuyukiume/life-manager/world/projects/brain-bulking/` を参照する。
5. この repo では、実行に必要な戦略要約・進捗・開発計画を管理する。
6. 重要な方針変更は `progress/weekly-status.md` または専用ドキュメントに残す。
