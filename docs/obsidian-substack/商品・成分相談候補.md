# 商品・成分相談候補

## このファイルの役割

読者から出た「これ必要？」「これ買うか迷っている」「この広告文句が分からない」を集める場所。

ここに入ったものを、Notes、memo、記事、BB Checker候補へ振り分ける。

## 優先度ルール

| 観点 | 内容 |
|---|---|
| 読者需要 | コメントや質問がある |
| 迷いやすさ | SNSや広告で判断しにくい |
| 初心者向け価値 | これから始める人にも役立つ |
| 生活への落とし込み | 食事、栄養、運動習慣に接続できる |
| 事業接続 | BB Checker、有料コミュニティ、案件に接続する |
| 専門確認負荷 | 自分で確認できる範囲か、外部確認が必要か |
