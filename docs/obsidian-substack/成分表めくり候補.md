# 成分表めくり候補

このファイル名は旧方針のもの。今後の正本は [[商品・成分相談候補]] にする。

Substackでは「成分表をめくれ」と押し出すより、「これ必要？」を一緒に考えるトーンに寄せる。

## 優先度ルール

優先度は以下で判断する。

| 観点 | 内容 |
|---|---|
| 読者需要 | コメントや質問がある |
| 誤解されやすさ | SNSで雑に語られやすい |
| 判断基準化 | 読者が今後も使える見方になる |
| 事業接続 | BB Checker、有料コミュニティ、案件に接続する |
| 専門確認負荷 | 自分で確認できる範囲か、外部確認が必要か |
