# Substack 制作ボード

## 使い方

このファイルは「今週何を出すか」を管理する場所。

来週以降の候補は [[Substack 記事案]] に置く。

投稿済みになったら [[Substack 公開ログ]] に転記する。

## ステータス

| ステータス | 意味 |
|---|---|
| 候補 | まだ出すか未確定 |
| 今週確定 | 今週出すことが決まった |
| 構成中 | 見出し/切り口を作っている |
| 執筆中 | 本文を書いている |
| 専門確認中 | 追加確認待ち |
| 品質ゲート中 | 表現/構成/CTAの確認中 |
| 投稿待ち | MCPで投稿できる状態 |
| 予約済み | 指定日時でSubstack予約済み |
| 投稿済み | 公開ログへ転記済み |
| 差し戻し | 事実、表現、導線に問題がある |
| 保留 | 今週は出さない |
