# Substack 投稿原稿

このフォルダには、実際に投稿する原稿を保存する。

## 命名規則

週ごとの投稿パッケージ:

```text
YYYY-MM-DD_WeekN_投稿パッケージ.md
```

単発記事:

```text
YYYY-MM-DD_記事タイトル.md
```

## 管理ルール

- 投稿予定は [[Substack 制作ボード]] で管理する。
- 投稿済みURL、post_id、note_id は [[Substack 公開ログ]] に記録する。
- Notesだけの短文は制作ボードに直接本文を書いてもよい。
- memoと保存版記事は原則このフォルダに原稿を残す。
