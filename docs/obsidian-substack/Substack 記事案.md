# Substack 記事案

## 運用ルール

- 保存版記事は毎週金曜21:00に公開する。
- Notesで反応を見てから記事化する。
- 読者から商品名や疑問が出たテーマを優先する。
- 疾患、医薬品、妊娠、未成年、競技規則が絡む場合は専門確認必須。
- Substackでは思想を押しつけず、「これ必要？」を一緒に考えるトーンにする。
- Substack上では `筋太郎` の個人アカウントとして、体験談・学習ログ・日記っぽく書く。
- Notesは自己紹介ではなく、フィットネス関連の体験談・問いかけを中心にする。
- AI活用は単体テーマではなく、筋トレ/栄養/健康情報整理に接続できる時だけ扱う。
