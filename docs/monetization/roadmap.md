## 基本方針

BB のマネタイズは信頼を換金する行為。

短期売上よりも、「こいつらが紹介するなら間違いない」という状態を先に作る。

| 優先 | 収益源 | 状態 | 次に必要なこと |
|---:|---|---|---|
| 1 | 有料コミュニティ | 設計中 | 価値定義、初期メンバー導線、Discord 設計 |
| 2 | BB Checker | 企画済み | MVP 要件、技術選定、データ schema |

| 6 | TikTok ライブ | 将来 | ライブ型、台本、運営負荷の見積もり |
| 7 | X / Threads 収益化 | 将来 | フォロワー・インプレッション条件の達成 |
| 8 | TikTok Creativity Program | 将来 | 1分以上動画の運用が必要 |

## BB Checker の位置づけ

BB Checker は単独アプリではなく、収益とコミュニティのハブ。

流れ:

```text
SNS投稿
  -> 成分表をめくる文化を作る
  -> BB Checker で実際に商品を判定
  -> 代替商品 / 詳細分析 / コミュニティへ誘導
```

## 直近で決めること

1. BB Checker の MVP 範囲
   - サプリのみか
   - 食品まで含むか
   - ルールベース判定の初期カテゴリ
2. 有料コミュニティの初期価値
   - 運営に直接相談
   - AI分析無制限
   - 商品リクエスト
   - 開発室
3. アフィリエイトの紹介基準
   - 3人全員が自腹で買うか
   - PR とアフィリの明示方法
   - 紹介頻度の上限
