# LINE フォーマット仕様

LINE オープンチャット投稿用の文字組みルール。**全7投稿でこの仕様を厳守する**。

## 骨格テンプレート（コピペそのまま LINE に貼れる形）

```
おはようございます！

[タイトル：13〜30字]

・[要点1]。
・[要点2]。
・[要点3]。

[一言コメント：1行、句点で終わる]。

▼今日からできるアクション
・[具体行動1]。
・[具体行動2]。
・[具体行動3]。

根拠：[完成形URL]
```

---

## 構造ルール

### 先頭固定文

- **必ず**「おはようございます！」で始まる
- 末尾は半角「!」ではなく **全角「！」**
- 直後に空行1つ

### タイトル

- 13〜30字（推奨 16〜24字）
- 主張が一目で分かる体言止め or 断定文
- 「？」で終わらせない（疑問形は LINE 上で弱く見える）
- カギ括弧での強調は OK（例：「ホエイ20gで筋合成は最大化する」）
- タイトルの後に空行1つ

### 要点ブロック（・ 3行）

- **句点（。）で必ず改行**する
- 1行 = 1事実 = 1つの主張
- 数値・出典の年・対象を入れる（例「2024年の RCT で〜」）
- 3行で完結する。4行目以降は禁止
- ブロック後に空行1つ

### 一言コメント

- BBトーン（断定・体言止め可、思想を一行で叫ぶ）
- AIっぽい言い回し禁止：「〜と言えるでしょう」「ケースバイケース」「個人差があります」「一概には」
- 1行で完結、句点で終わる
- 直後に空行1つ

### アクションブロック

- ヘッダー固定: `▼今日からできるアクション`（▼は黒三角、全角）
- 行頭は `・`（中黒、全角）
- 数字・量・タイミング込み（例「朝食時にホエイ20g」「就寝90分前に湯船15分」）
- 動詞ベース（測る/記録する/置く/飲む/歩く/抜く/置き換える 等）
- **抽象語禁止**：意識する / 気をつける / 心がける / 考える / 大切にする
- 1〜3個（情報の重さで調整、最低1個）
- 直後に空行1つ

### 根拠リンク

- 行頭固定: `根拠：` （半角コロンではなく全角コロン）
- 完成形 URL（短縮 URL は使わない）
- 1〜2本まで。3本以上は本文が長くなりすぎるので避ける
- 複数のときは改行で並べる（`根拠：` を2回繰り返す）

---

## 改行ルール（最重要）

LINE は「。の途中で折り畳まれない」のが鉄則。**句点ごとに必ず改行する**。

### NG 例

```
朝食時に体温が低いとプロテイン合成が下がる。だから起床後30分以内に20g摂れ。
```

### OK 例

```
朝食時に体温が低いとプロテイン合成が下がる。
だから起床後30分以内に20g摂れ。
```

箇条書き（・）の中も同じ。1行に2文を詰め込まない。

## 行数の目安

タイトル・空行・固定ヘッダーを除いた**実質コンテンツ行数**:

| 項目 | 行数 |
|---|---:|
| 要点 | 3 |
| 一言コメント | 1 |
| アクション | 1〜3 |
| 根拠 | 1〜2 |
| **合計** | **6〜9** |

「5〜7行＋根拠」を目安にしつつ、アクションを充実させる場合は最大9行まで OK。

---

## 禁止事項

| 禁止 | 理由 |
|---|---|
| 絵文字（本文） | LINE OC は科学コミュニティ、軽く見える |
| ハッシュタグ | LINE では機能しない、ノイズ |
| 短縮 URL（bit.ly等） | 信頼性が落ちる、リンク先が予測できない |
| 半角！半角？ | 全角で統一（おはようございます！の絵に合わせる） |
| 自己紹介・誘導文 | 既メンバー向けなので不要 |
| Threads/Note 用の L1-L4 誘導 | このスキルでは入れない |

## カテゴリ別の文体微調整

### Tips（科学的根拠ベース）

- 一言コメントは「論文/データから何が見えるか」を一行で
- 根拠 URL は PubMed / 公式機関を優先
- アクションは「実験的に試せる範囲」（1日試してみて、的なもの）

### News（直接系：フィットネス・栄養・サプリ・規制）

- 一言コメントは「これがあなたの選択にどう影響するか」
- 根拠 URL はニュース原文（Google News から元記事へ飛ぶ）
- アクションは「この情報を踏まえて何を変えるか」

### News（間接系：原料相場・サプライチェーン・他業界規制）

- 一言コメントは「直接見えにくい因果を一行で翻訳」（例「石油↑→輸送費↑→ホエイ価格↑」）
- 根拠 URL は Bloomberg / 日経などの一次ソース
- アクションは「先回りして買う/減らす/置き換える」

## サンプル投稿（参考）

### Tips サンプル

```
おはようございます！

ホエイは「20g×4回」が筋合成の天井

・1回20gを超えるとロイシン応答は頭打ち（2014年 Areta ら）。
・4時間ごとに分けるパターンが最もMPSが高い。
・寝起きと寝る前の2回は、別途ロイシン2.5gでも代替可能。

タンパク質は「総量」より「分配」で効く。

▼今日からできるアクション
・朝食時にホエイ20gをシェイカーで飲む。
・昼食と夕食でそれぞれ20g、肉/魚から摂る。
・就寝1時間前にホエイ20gを追加で1杯。

根拠：https://pubmed.ncbi.nlm.nih.gov/24257722/
```

### News（間接）サンプル

```
おはようございます！

原油↑でホエイプロテインは年内に値上げ確定

・ニュージーランド産ホエイの輸送費が前年比18%上昇。
・主要メーカーは2025年Q3〜Q4に5〜10%の値上げを既に告知済み。
・国内 EC では並行輸入品が先に在庫薄になっている。

買うなら今、選ぶなら国内製造への切替も視野。

▼今日からできるアクション
・通っている EC のカートに3kg袋を1袋仕込む。
・国内製造（明治・グリコ等）の成分表を1度比較する。

根拠：https://www.bloomberg.com/news/...
根拠：https://www.nikkei.com/article/...
```

## 文字数の目安

1投稿あたりの**実文字数**（タイトル含む、空行除く）:

- 最小: 180字
- 標準: 250〜350字
- 最大: 450字

LINE のスクロール1〜2画面に収まる量を意識する。
