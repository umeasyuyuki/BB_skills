# ソース優先順位とクエリパターン

Phase 1 で各エージェントが情報源を選ぶ際のルール。

---

## カテゴリ別ソース表

### Tips 担当（3本生成）

主に科学的根拠ベース。論文・公式機関・ガイドラインから発掘。

| 優先 | ソース | URL パターン | 強み |
|---|---|---|---|
| 1 | PubMed | `pubmed.ncbi.nlm.nih.gov` | RCT・メタアナリシスの一次情報 |
| 2 | ACSM | `acsm.org` | 米国スポーツ医学会、運動処方の権威 |
| 3 | NSCA | `nsca.com` / `nsca-japan.or.jp` | 筋力・コンディショニングの権威 |
| 4 | Examine.com | `examine.com` | サプリ成分のエビデンス整理（有料コンテンツ多いが要約は無料） |
| 5 | Reddit r/fitness | `reddit.com/r/fitness` | 実践者ベースの議論。Wiki と FAQ は出典明記が厳しい |

検索ラウンド（gemini で実行）:

```
Round 1: 「{topic} RCT 2024 OR 2025 site:pubmed.ncbi.nlm.nih.gov」
Round 2: 「{topic} meta-analysis recent」
Round 3: 「{topic} site:examine.com」
Round 4: 「{topic} site:reddit.com/r/fitness wiki」
Round 5: ACSM/NSCA position stand を確認
```

### 直接ニュース担当（3本生成）

フィットネス・栄養・サプリ・規制の直接系ニュース。

| 優先 | ソース | カバー領域 |
|---|---|---|
| 1 | Google News（fitness 関連） | 横断的なニュース集約 |
| 2 | 日経ヘルスケア | 国内ヘルスケア業界・規制 |
| 3 | 健康産業新聞 | サプリ業界の業界紙 |
| 4 | NIH ODS | 米国サプリ規制の最新 |
| 5 | 厚労省 / 消費者庁 | 国内規制・回収情報 |

検索ラウンド:

```
Round 1: Google News で「サプリメント 規制 {current_year}」「プロテイン 新発売 {current_year}」
Round 2: 「機能性表示食品 撤回 {current_year}」「健康食品 回収 {current_year}」
Round 3: 「クレアチン 新エビデンス {current_year}」等、トレンド成分の最新動向
```

### 間接ニュース担当（1本生成）

直接フィットネスではないが、価格・供給・規制を通じて影響する話題。

| 優先 | ソース | 拾うべきテーマ例 |
|---|---|---|
| 1 | Bloomberg | 原油・乳価・農産物相場 |
| 2 | 日経新聞 | 為替・関税・物流コスト |
| 3 | 日経ヘルスケア | 国内医療制度改正 |
| 4 | Reuters | 国際的なサプライチェーン障害 |

検索ラウンド:

```
Round 1: 「whey protein price {current_year}」「dairy commodity index」
Round 2: 「原油価格 物流コスト {current_year}」「円安 輸入 健康食品」
Round 3: 「{他業界の規制} 健康食品 影響」
```

間接ニュースは**月に2〜3本程度**しか良いネタがないので、空振りした日は直接ニュースで4本に振り替えて良い。

## 各エージェントへ渡す共通指示

```
■ 重要な制約
- 重複候補リスト（過去30日のタイトル）と類似度70%以上のテーマは選定NG
- URLは実在確認済みのもののみ。架空URLは絶対禁止
- 1次ソースを必ず1つ含める（まとめサイトのみは不可）
- 推測と事実を明確に区別する
- 数値・年・対象を本文に含めること（「研究によると」だけはNG）

■ 翻訳ルール
- 英語の論文や海外ニュースは日本語に翻訳して要点を抽出
- 専門用語は中級者でも分かるレベルまで噛み砕く（中・上級者向けだが用語の壁は下げる）
- 1次ソースの URL はそのまま記載（翻訳元として）

■ 倫理
- メーカー名や商品名を出すときは、利益相反になり得ない範囲で
- 特定銘柄の推奨は避け、「カテゴリとしての選択肢」として紹介
```

## 調査エンジン優先順位（CLAUDE.md 準拠）

1. **第一選択: Gemini CLI** (`gemini -p` with `gemini-3-pro-preview`)
2. **レート制限時: gemini-2.5-pro**
3. **それも失敗: Codex CLI** (`codex exec`)

切替時はユーザーに1行で報告（例：「Gemini レート制限のため Codex に切替」）。

## ネタが枯渇したときの逃げ道

7本揃わないときの優先度（上から試す）:

1. PubMed の **直近1週間の新着**（`pubmed.ncbi.nlm.nih.gov/?filter=datesearch.y_1`）から拾う
2. 過去31〜60日の自家投稿で**反応が良かった**テーマの **続編**（重複候補リストには入っていないので OK）
3. 時事ネタ（祝日・季節・気温）に絡めた **生活ハック系 Tips**（例：花粉症シーズン × プロテイン、夏 × 電解質）
4. それでも揃わなければ **6本で出力**して、ユーザーに「明日2本にする？それとも今日1本追加で書く？」と確認

## 過去ネタの再放送 NG / OK 判定

| ケース | 判定 |
|---|---|
| 同じ研究、同じ結論で書き直し | NG（重複） |
| 同じ研究、別の切り口（女性向け / 高齢者向け） | OK（タイトルが違えば） |
| 続報・追試論文が出た | OK（明確に「続報」と書く） |
| 同じテーマ、新しいニュースが出た | OK |
| 価格・規制が更新された | OK |
