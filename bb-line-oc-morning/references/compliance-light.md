# 薬機法 簡易チェック

LINE オープンチャットはクローズドコミュニティだが、最低限の自衛として実施。`tiktok-fit-compliance-check` のフルチェックを軽量化したもの。

---

## 判定基準

| ラベル | 意味 | 対応 |
|---|---|---|
| Red | 絶対NG表現を検出 | Phase 2 にフィードバック → 書き直し（最大2回） |
| Yellow | 修正推奨だがクローズド配信なら許容圏 | 警告ログのみ、原文維持 |
| Green | 問題なし | そのまま Phase 4 へ |

---

## 絶対NG表現（Red）

### 効果の100%断定

| NG | 安全な言い換え |
|---|---|
| 痩せる | 体脂肪が減りやすい環境を作る |
| 太らない | 体重維持に寄与する |
| 筋肉がつく | 筋合成を促す / 筋発達をサポートする |
| 病気が治る | 体調管理に役立つ |
| 目が良くなる | 目の疲れを和らげる可能性 |
| 若返る | エイジングケアの土台になる |

### 医療行為と誤認される表現

- 「○○を予防する」（医薬品的）→「○○リスクを下げる方向に作用する可能性」
- 「○○が治る」（医薬品的）→「○○の改善が報告されている」
- 「○○が増える / ○○が減る」が断定 → 「研究では平均で○○ポイント変化が見られた」

### 過剰一般化

- 「誰でも」→ 「○○の条件下で」
- 「絶対に」→ 「研究では」
- 「100%」→ 「メタ分析の結果」
- 「即効性」→ 「短期間（○週間）で変化が見られた」

---

## 条件付きOK（Yellow）

LINE OC 内なら通すが、表現を意識する余地あり。

| 表現 | 注意点 |
|---|---|
| 〜をサポートする | 主語と対象を明確に |
| 〜の維持に役立つ可能性 | 「可能性」を残す |
| 〜が報告されている | 出典明記 |
| 〜は最強 | BBトーンで許容、ただし主観であることを明示 |

---

## 重点チェック項目

1. **サプリの効果断定**
   - 「クレアチンで筋肉がつく」 → 「クレアチンは筋出力を上げ、結果として筋発達を促しやすい」
2. **根拠の強さと主張の強さの不一致**
   - 1本の小規模 RCT で「これが正解」と断定するのは NG
   - メタアナリシスがあれば「メタ分析でも一致」と書ける
3. **適用対象の過剰一般化**
   - 「男性向け RCT」を「誰でも」と拡張するのは NG
4. **量・対象・注意点の欠落**
   - 「ホエイは20gがベスト」だけだと不十分
   - 「体重70kgの男性、トレーニング直後の場合」など条件を明記

---

## チェック実行手順（Phase 3 内）

1. Phase 2 で生成された7投稿それぞれに対して以下を実行:
   - 上記 NG 表現リスト（Red）に**完全一致 / 部分一致**するか確認
   - 一致したら Red 判定、安全な言い換え案を Phase 2 にフィードバック
2. NG 表現に該当しないが、以下のシグナルがあれば Yellow:
   - 数値が無い断定（「〜が増える」だけ）
   - 主語が曖昧（「みんな」「誰でも」）
   - 出典 URL に飛んでも該当の主張が確認できない疑い
3. 全7投稿が Green / Yellow なら Phase 4 へ

---

## LINE OC 特有の許容ライン

LINE OC はクローズドかつメンバーが既に文脈を理解しているため、Threads / Note より**やや緩い**運用にする:

| 観点 | Threads/Note | LINE OC |
|---|---|---|
| BBトーン（断定・体言止め） | OK | OK |
| 「最強」「終わってる」等の強表現 | 慎重に | 許容（ただし論証付き） |
| ジョークトーン | 控えめ | やや許容 |
| 効果の断定 | 厳格に NG | 厳格に NG（クローズドでも変わらず） |
| 量・対象・注意点 | 必須 | 必須 |

「効果の断定」と「量・対象・注意点の明記」は媒体問わず厳守。これは薬機法の根本ライン。

---

## 自動修正の判断

Phase 2 が書き直しを2回連続で失敗した場合:

- **Red 内容が原文の主旨そのもの**（例：「○○で痩せる」が記事の主張）→ ユーザーに「テーマ自体を変えるか確認」と通知
- **Red 内容が局所的な言い換えで済む**（例：「絶対」を「研究では」に）→ Phase 2 が3回目で機械的に置換して継続

---

## チェックの粒度

LINE OC は1日1本しか投稿しない（人間が選ぶ）ため、**疑わしきは Yellow に倒す**運用。Red は本当に法務リスクがあるものだけに限定。Yellow は「次回からは気をつける」程度の警告で、当日の投稿は許可する。
