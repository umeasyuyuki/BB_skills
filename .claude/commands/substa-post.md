# Substack Post Shortcut

これは `/substack-post` の短縮版。Substackの長文 `Post` を作成する。

入力:

```text
$ARGUMENTS
```

## 実行

`.claude/commands/substack-post.md` の手順を読み、同じ品質ゲートと投稿手順で実行する。

特に守ること:

- 投稿者は `筋太郎　〜フィットネスとAI大好きマン〜`
- 一人称は `僕`
- 体験談から入り、読者が使える判断基準へ落とす
- 敬語ベース、温度高め、真面目な注意書き以外は `！` 寄り
- `🔥` `💪` を自然に使う
- 複数人運営、公式感、監修チーム感は出さない
- 健康/サプリ効果は断定しない
- 明示許可なしに即時公開しない
- 「予約して」があれば、品質ゲート後にSubstack予約APIで予約する
- メール配信ありは、ユーザーが「メールあり」と明示した場合だけ
- 下書き/予約後は `Substack 公開ログ.md` と `Substack 制作ボード.md` を更新し、Obsidian vaultへ同期する

## 使い方

```text
/substa-post マグネシウムは筋トレ民に必要なのか
/substa-post マグネシウムは筋トレ民に必要なのか 下書き作成
/substa-post マグネシウムは筋トレ民に必要なのか 2026-05-15 21:00 予約して
/substa-post マグネシウムは筋トレ民に必要なのか 2026-05-15 21:00 予約して メールあり
```
