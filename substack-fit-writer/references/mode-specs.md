# Mode Specifications

## Mode: Note

目的: 発見、会話、Restack、軽い信頼形成。

文字数:

- 基本: 100〜300字
- ミニ解説: 300〜500字まで可

構成:

```text
1行目: 違和感・発見・問い
本文: 理由、具体例、軽い解釈
最後: コメントしたくなる問い
```

ルール:

- 1投稿1テーマ
- リンクを貼るだけにしない
- 単体で読める価値を入れる
- 断定より「判断材料」を渡す
- 最後は会話の余地を残す

出力数:

- 通常は3案出す
- それぞれ切り口を変える: 発見型 / 問い型 / ミニ解説型

## Mode: memo

目的: 学びの途中経過を共有し、読者と一緒に考える。

文字数:

- 800〜1,500字

構成:

```markdown
# タイトル

## 今日気になったこと
## 調べてわかったこと
## 自分たちの解釈
## 実際にどう使うか
## 読者への問い
```

ルール:

- 完璧な結論を急がない
- 調べた過程、迷った点、判断基準を残す
- 研究、成分、体験、違和感を混ぜる
- 読者がコメントで参加できる余白を残す

## Mode: 記事

目的: 保存、信頼、無料購読、有料化の土台作り。

文字数:

- 1,500〜3,000字

構成:

```markdown
# タイトル

## 先に結論
## なぜこのテーマが大事か
## よくある誤解
## 根拠・仕組み
## 実践するならどう考えるか
## 例外・注意点
## まとめ
## コメント/購読CTA
```

ルール:

- 読者が今日から使える判断基準を必ず入れる
- サプリや健康効果は主張の強さを抑える
- 必要なら「個人差」「前提条件」「医療判断ではない」注意を入れる
- 最後はSubstack内の購読、コメント、次回テーマ希望につなげる

## Mode: full set

1テーマから以下を作る。

1. Note 3本
2. memo 1本
3. 記事 1本
4. 記事公開後に出す再投稿Note 2本

流れ:

```text
Noteで反応を見る
memoで軽く深掘りする
記事で保存版にする
再投稿Noteで記事へ流す
```

full setでは、各媒体の役割が重複しないようにする。Noteは会話、memoは学びの記録、記事は保存版として書く。

## Substack-Specific Guidance

- Noteは短く、会話と発見を作る
- memoは「学びの共有」として少し緩くてよい
- 記事はアーカイブされる前提で、あとから読んでも価値が残る構成にする
- 外部SNSやLINEへの導線は補助にする
- 初期導線はSubstack内のコメント、購読、Restackを優先する
- 海外読者を狙う場合は、必要に応じて日英併記の短いNote案も提案する

## Image Guidance

画像案を求められた場合のみ出す。

- Note画像: 1:1 または 4:5
- 記事プレビュー: 1200x630pxを基本
- デザイン: 1画像1メッセージ
- 中央寄せ、余白多め、過度な赤文字禁止
- サプリや健康効果のビフォーアフター表現は慎重に扱う
