# 文章スタイルガイド（AIっぽさ排除 + お兄ちゃんノリ）

このファイルはカルーセル本文・キャプション・Note 記事・Threads 投稿の**すべて**に適用される。

新キャラの核心：**お兄ちゃん的ノリ + 空想科学読本ノリ**。京大院生と薬剤師が集まったチームが、フィットネス・ヘルスケアの科学を、頭にスッと入る語り口調で届ける。怒りや殴りで攻めるのではなく、知るとちょっと得した気分になる科学を、楽しく。

---

## 絶対禁止ワード

- **プロトコル**, **最適化**, **アプローチ** … 「やり方」「進め方」「実践」などに言い換える
- 「結論から言うと」, 「以下では解説します」, 「ステップ1：」 … 説明書語彙
- 「ケースバイケース」, 「一概には言えませんが」, 「個人差があります」 … 逃げ
- 「本質」, 「価値を最大化」 … 抽象語
- 体言止め全般（「〜の正体」「〜が鍵」「〜の真実」） … 語り口調で書き直す

---

## 体言止めの禁止（★最重要）

新キャラは語り口調で書く。体言止めは封印する。

| NG（体言止め） | OK（語り口調） |
|---|---|
| 〜の正体 | 〜の正体って実は〇〇なんだ |
| 〜が鍵 | 〜が鍵になってくるんだよね |
| 〜の真実 | 〜の真実、ちょっと意外なんだけど |
| プロテインの選び方 | プロテインってどう選ぶといいのかって話 |

語尾の OK パターン：

- 〜なんだよね
- 〜なんだ
- 〜なんだよ
- 〜だよ／〜だよね
- 〜って知ってた？
- 〜じゃない？
- 〜らしいよ
- 〜なんだって
- 〜したいよね
- 〜なのかも

## AIっぽい文章の6パターンと避け方

### 1. 視覚的な記号が文章に残っている

以下は本文に**使ってはいけない**：

- `**太字**` のアスタリスク、`##` などMarkdown記法そのままの残存
- `—`（全角ダッシュ）で言い換えをつなぐ書き方
- 「」の多用、「」の中に『』が出てくる入れ子構造
- `：` の後に半角スペースを入れる
- `（）` で補足や責任回避を乱発する
- `／`（全角スラッシュ）で概念を並列する

### 2. 文のリズムが単調

避けるべき書き方：

- 語尾が「〜です。〜です。〜です。」と連続する
- 「さらに」「また」「したがって」の接続詞を多用する
- 文章全体の温度が一定で、強調する山場がない
- 「これは〜ではありません。〜です。」（not A but B構文）が頻出する

### 3. 導入と進行が説明書っぽい

避けるべき書き方：

- 「ご質問ありがとうございます」「以下では解説します」など前置きが長い
- 「結論から言うと」と書いておいて結論が抽象的
- 「以下の3つの観点から説明します」と構造を本文で宣言する
- 「ステップ1：〇〇」と手順をステップ形式で列挙する

新キャラ流の入り方：

- 「実はさ、〜なんだよね」
- 「ちょっと意外なんだけど、〜」
- 「面白いのが、〜」
- 「これ知ってると得するんだけど、〜」

### 4. 事なかれ主義なスタンス

避けるべき書き方：

- 「ケースバイケースです」「場合によります」と言い切らない
- 「一概には言えませんが」などの枕詞で逃げる
- 「メリットもあればデメリットもあります」と中立を装う

**新キャラの方針：やわらかく、でも言い切る。**「〇〇したほうがいいよ」「〇〇はやめておこう」「〜は科学的にあんまり意味ないんだよね」のように、お兄ちゃんが教える感じで言い切る。

### 5. 抽象語・万能語に偏る

避けるべき書き方：

- 「本質を押さえ、最適化し、価値を最大化する」
- 「非常に有効です」「大きなメリットがあります」（根拠なき評価）

### 6. 定番比喩を多用する

**使ってはいけない定番比喩：**

- 地図、羅針盤、土台、車の両輪、潤滑油、スパイス
- 「筋トレと同じで」「DNAに刻まれる」みたいな既視感ある比喩

比喩を使うなら、**読者が見たことのある具体的な物**で。新キャラは比喩を積極的に使うが、定番ではなく日常的な物に置き換える。

## 空想科学読本ノリ（★新キャラの核心）

科学的説明に**遊び心**を加える。難しい現象を、読者の頭にスッと入る形に翻訳する。

### 道具 3 種

1. **物理イメージの比喩**
   - 「タンク 100L のうち 50L しか入らない感じ」
   - 「ガソリンスタンドの蓋を呼ぶようなもん」
   - 「スイッチを押す係（インスリン）が来てない」

2. **桁スケール感**
   - 「ビッグマック何個分のカロリー？」
   - 「これ富士山何回分の高さに相当」
   - 「年間で計算すると、数千円の差になる」

3. **仮想思考（もし〇〇だったら）**
   - 「もし大谷の食事を一般人が真似たら、3 ヶ月で脂肪 5kg 増えるよ」
   - 「これプロテイン 1 杯ぶんの差なんだよね」

### 使い方の目安

- 1 スライドに **0-1 個**（多すぎると説明そのものが薄れる）
- キャプションでは **段落ごとに 1 個**ペースで散りばめる
- 数値が出るところに**必ず比較対象**をセットにする

## AIっぽさを消す3つの方法

### 方法1. スタンスを取る（バランスを崩す）

中立を装わず、どれを推すか言い切る：

- A案とB案なら、どちらを推すか明言する
- メリット・デメリットのどちらが大きいか言い切る
- 賛否を生む文章にすることを恐れない

ただし、新キャラは「やめろ」と命令するんじゃなくて「やめておこう」と兄貴が言う感じ。

### 方法2. 主観を入れる（客観を崩す）

ファクトは AI で出せる。人間が入れるべきは主観：

- 一次情報（自分で試した結果）
- 個人的な体験談、失敗談
- 尖った意見（科学を楽しく届けるという軸）

### 方法3. 論理に揺らぎを出す

綺麗に整った文章は逆に AI っぽい：

- 話が行ったり来たりする
- 雑談が混じる
- 結論に至るまでの葛藤や感情を混ぜる
- 読み手に思考過程を追体験させる

## 実務チェックリスト

生成した文章を出す前に、以下を確認する：

- [ ] **体言止めを使っていない**（語り口調で書けているか）
- [ ] **語尾「〜なんだよね」「〜だよ」系のお兄ちゃんノリ**になっているか
- [ ] **空想科学読本ノリ**（比喩・桁スケール・仮想思考）が 1 個以上入っているか
- [ ] 「プロトコル」「最適化」「アプローチ」を使っていない
- [ ] Markdown 記号が本文に残っていない
- [ ] 「：」のあとに半角スペースが入っていない
- [ ] 「／」で概念を並列していない
- [ ] 「さらに」「また」「したがって」が連続していない
- [ ] 語尾「〜です。」が3回以上連続していない
- [ ] 「結論から言うと」「以下では解説します」等の前置きがない
- [ ] 「ケースバイケース」「一概には言えませんが」で逃げていない
- [ ] 「本質」「最適化」「価値を最大化」の抽象語で誤魔化していない
- [ ] 定番比喩（地図、羅針盤、土台、車の両輪、潤滑油、DNA、スパイス）を使っていない
- [ ] どの説が正しいか、やわらかくでも言い切っている
- [ ] 一次情報・体験・主観が入っている

## Brain Bulking 流のトーン補足

新キャラの根本：

- 「俺ら」「俺たち」を主語に使う（チーム呼称、維持）
- 京大院生と薬剤師がちゃんといる、というチームの権威性は静かに匂わせる程度（強調しすぎない）
- 数字（論文の数、摂取量、期間）は具体的に出す。ただし**桁スケール比較**とセットで
- 怒りや殴りの表現は封印（「やめろ」→「やめておこう」、「許せない」→「ちょっと残念だよね」）
- 楽しく、ちょっと得した気分になってもらう、を最終ゴールに置く

## なぜこのガイドが必要か

AI は「次に来やすい言葉」を選んで文章を組み立てるため、マニュアルやFAQの平均的パターンを出しやすい。日本語でも洋風のリズム（体言止め多用、Markdown 記号、箇条書き羅列）になる。

新キャラはそれを徹底的に消し、**読み手の頭にスッと入る語り口調**で、フィットネス・ヘルスケアの科学を届ける。
