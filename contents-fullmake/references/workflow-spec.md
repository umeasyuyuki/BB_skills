# ワークフロー仕様

## 入力

- 必須: `category`, `theme`
- 任意: `depth_mode`（`standard` or `deep`）

## カテゴリ

| カテゴリ | コード名 | 例 | 配分目標 |
|---|---|---|---:|
| 比較系 | `compare` | 〇〇 vs 〇〇 | 25% |
| 誤認訂正系 | `debunk` | 世間の間違いを正す | 25% |
| 成分解説系 | `ingredient` | 牛乳・アシュワガンダ等 | 20% |
| エンタメ系 | `entertainment` | 固有名詞 × 空想科学読本 | 15% |
| 発見解剖系 | `discovery` | 異常な事例を科学で分解 | 15% |

## 深掘り判定

以下のどれかで `deep`：

- 保存率 0.5% 以上
- 作用機序を誤解すると実践を間違えやすい
- 筋トレ界隈のトレンド性が高い

## カテゴリ別の必須項目

### compare（比較系）

- 比較対象の明示（A vs B、または ランク形式）
- PFC、価格、1円あたりタンパク質量（栄養比較の場合）
- 特筆成分とその効果
- 作用機序の噛み砕き説明
- 結論（どちらを推すか／どれが1位か）の言い切り

### debunk（誤認訂正系）

- 主張原文（誰が何を言っているか）
- 判定（支持／一部支持／不支持）
- どの条件なら成り立つか
- 正しい実践アクション

### ingredient（成分解説系）

- 誰向けか
- 結論（何をどう摂るか）
- 結論を支える要素（2-3 個）
- 実行条件または実行方法
- 注意点
- 詳しい作用メカニズム（必要時のみ補足）

### entertainment（エンタメ系）

- 固有名詞（実在の選手・有名人・作品など）
- 「もし科学的に検証したら」の切り口
- 桁スケール感（極端な数値で驚かせる）
- 学びへの着地（笑った後に保存価値を残す）

### discovery（発見解剖系）

- 異常な事例の提示（数字で驚かせる）
- 科学的分解（栄養 / 生理学 / 物理）
- 真似できる要素 vs できない要素の切り分け
- 実用に落とす結論

## エージェント実行フロー

```
┌─────────────────────────────────────────────────────────┐
│  オーケストレーター（メインエージェント）                     │
│  テーマ受取 → カテゴリ判定 → 深掘り判定                      │
└──────────────┬──────────────────────────────────────────┘
               │ Phase 1（researcher 単独）
               ▼
        ┌──────────────────────┐
        │  researcher           │
        │  tiktok-fit-research  │
        │  ・科学的根拠収集     │
        │  ・PubMed/公式データ  │
        │  ・既存情報との差別化軸│
        └──────────┬───────────┘
                   │ Phase 1.5（タイトル生成→評価→選択）
                   ▼
            ┌─────────────────────────────────┐
            │  title-generator → title-evaluator │
            │  → TOP5 提示 → ユーザー選択 or 自動採用 │
            └──────────┬──────────────────────┘
                       │ Phase 2（カルーセル単独生成）
                       ▼
                ┌──────────────────┐
                │ carousel-writer   │
                └────────┬─────────┘
                         │ Phase 3-5（チェック→Notion→画像）
                         ▼
                  （Phase 5 は承認ゲート後）
```

Note 記事 / Threads 投稿は本スキルから分離され、`bb-note-threads` スキルが担当する。
競合分析（旧 competitor-analyst）は廃止し、差別化軸の抽出は researcher の調査範囲に統合した。

### Phase 1 researcher への指示

`tiktok-fit-research` を起動する際、以下を必ず含めるよう指示する:

1. **科学的根拠収集**（PubMed・公式データ・査読論文 5-8 件）
2. **既存情報との差別化軸**: テーマで既に流通している主張・常識・通説を 2-3 点提示し、それを覆す or 補強する独自角度を明示
3. **薬機法上の注意点**（サプリ・栄養テーマの場合）

## 出力制約

- Markdown で出力
- **画像カルーセルは枚数自由（1 画像 1 メッセージ徹底の結果として決まる、目安 8-15 枚）**
- 1枚目は 13-25 文字（挑発）= Phase 1.5 採用タイトルのカルーセル微調整版
- 2枚目以降は **40 字以内・4 行以内**（情報量超過時は即分割）
- **1枚 1 メッセージを厳守**（迷ったら即分割）
- 各枚に感情ラベル（感情設計列）を必ず付与する
- 総まとめ表を 1 画像必ず含める（CTA の 1 つ手前に配置）
- 最終成果物は `tiktok-fit-notion-publisher` で Notion 保存する
- 返答末尾に `保存対象サマリー` と `Notion 保存結果` を含める

## 感情設計フレームワーク（役割ごと、枚数自由）

★ **枚数固定ではなく役割固定**。各役割は最低 1 枚、情報量が多ければ複数枚に分割する。1 メッセージ 1 画像を徹底する。

| 役割 | 必要枚数 | 感情設計 | 内容 |
|---|---|---|---|
| 挑発 | 1 枚以上 | ドキッ | スクロール止める一撃。フック 3 点セット |
| 問題提起 | 1 枚以上 | 不安 | 「お前ら気づいてるか？」読者の現状を名指し |
| 証拠 | 2-4 枚 | 「え、マジで？」→ 怒りの種 → 差が際立つ | 1 枚 1 数字・1 比較で分割 |
| 思想爆発 | 1-2 枚 | 怒り着火 → 共感・覚醒 | BB の怒りと信念を "俺らの意見" として |
| 正解（実用） | 1-3 枚 | 「助かる」 | 1 メッセージずつ。実践方法・選択肢を分割 |
| まとめ表 | 1 枚 | 信頼 | 全体像の対照表（表は 1 枚に収める） |
| 宣言（CTA） | 1 枚 | 宣言・帰属 | BB が何者か、次も見る理由 |

合計枚数の目安: **8-15 枚**。テーマの情報密度で決まる。「10 枚に揃える」ことを目的化しない。

## 事実 × 思想の二段構え

- **事実パート**: 淡々と証拠を並べて信頼を積む。法的に問題のない客観的事実のみ
- **思想パート**: 事実を踏まえた上で、BB の怒りと信念を "俺らの意見" として叫ぶ。意見表明であり法的にも安全
- **実用パート**: 正しい選択肢と実践方法を渡す。保存価値を担保する
- **ブランドパート**: 宣言＋フォロー CTA で BB への帰属を促す

## CTA 候補

- 後で見返す用に保存
- 次の買い物前に保存
- 比較表を保存
