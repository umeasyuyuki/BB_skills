# Quality Gates

完了前に必ず確認する。

## Output

- 最終出力が5セクションだけになっている
- セクション順が `タイトル案 -> 台本 -> 画像生成プロンプト -> まとめ表 -> キャプション`
- 画像リンク、Driveリンク、Pillow生成結果を出していない

## Title

- 候補が5〜6本ある
- 採用タイトルが1つ明示されている
- 採用理由が1〜2行で書かれている

## Script

- 6〜7枚構成になっている
- 各スライドに `上部 / 中部 / 強調語` がある
- 4枚目・5枚目は必要な場合だけ入っている
- 6枚構成でも `まとめ・今日からできるアクション` と `コメント誘導` が残っている

## Image Prompt

- ChatGPT画像生成Projectにそのまま貼れる1本のプロンプトになっている
- 全スライド分の指示が入っている
- 上部・中部・下部キャラクターの固定レイアウトが明記されている
- 日本語テキストを変更しない指示が入っている
- 下部に本文テキストを置かない指示が入っている

## Summary Table

- Markdown表で出ている
- Notionにそのまま貼れる
- 画像生成プロンプトとは分離されている

## Caption

- TikTok投稿として使える
- LINEオープンチャットURLが入っていない
- 過剰なMarkdown装飾がない
- 目安900〜1600字

## Compliance

- 薬機法・医療断定・誇大表現を避けている
- 「絶対」「治る」「改善する」など危険な断定を必要に応じて弱めている
- 馴染みのない専門用語を説明なしで出していない

## Chain Menu (該当時のみ)

`chain_menu` カテゴリの場合のみチェックする。

- 商品数が3〜5選の範囲に収まっている
- 各商品スライドにPFC（`P○g F○g C○g 約○○kcal`）が入っている
- 各商品スライドに成分の効き1行が入っている（PFC再掲ではなく、効き方の言語化）
- 増減量ラベル `[増量]` `[減量]` `[両用]` が各商品の上部に入っている
- PFC公式公開なしの場合、スライド・まとめ表・キャプションの3箇所に「目安」「実測ベース」の注記が入っている
- まとめ表が `商品 / 用途 / P / F / C / kcal / 成分の効き` の7列構成になっている
- キャプションの商品紹介ブロックが箇条書きではなく段落構成になっている
- 商品ごとの成分の効きが「ヘルシー」「体に良い」のような抽象語ではなく、`ビタミンB1が糖代謝を助ける` のような具体的な働きの言語化になっている
