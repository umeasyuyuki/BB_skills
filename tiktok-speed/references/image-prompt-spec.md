# Image Prompt Spec

## Purpose

Claude Codeは画像を生成しない。ChatGPTブラウザ版の専用Projectに貼る「毎回の画像生成プロンプト」を作る。

## Prompt Requirements

プロンプトは1本にまとめる。サムネイル、本文、まとめ表を分けない。今回の高速版では、7枚すべてを同じ投稿デザインとして作る。

固定レイアウト:

- 上部: メインコピー
- 中部: 補足コピー
- 下部: 添付キャラクター

固定デザイン:

- 1:1
- TikTokカルーセル用
- 全スライドで文字位置、余白、キャラクター位置を統一
- 重要語だけ赤
- 補助ラベルは青を使ってよい
- 背景は白または淡色
- スマホで読める大きな文字
- 日本語テキストは一字一句変更禁止

## Prompt Template

```text
以下のTikTokカルーセル画像を作成してください。

投稿タイトル:
{ADOPTED_TITLE}

枚数:
{SLIDE_COUNT}枚

共通デザイン:
- 画像比率は必ず1:1。
- 各画像はTikTokカルーセル用。
- 文字は上部と中部に配置する。
- 下部には添付キャラクターを配置する。
- 全スライドで、文字位置、キャラクター位置、余白、色の使い方を統一する。
- 視聴者の目線が上下左右に大きく動かないようにする。
- 日本語テキストは下記の文言を一字一句そのまま使う。
- 勝手な言い換え、要約、追加、削除は禁止。
- 重要語だけ赤で強調する。
- 背景は白または淡い色を基本にする。
- 装飾を増やしすぎない。
- スマホで一瞬見ても読めるように、文字は大きく、行数は少なくする。
- 各スライドは別画像として出力する。
```

6枚構成にする場合は、不要なSlide 4またはSlide 5を削除し、番号を詰める。

## Text Limits

- 上部: 8〜18字目安
- 中部: 12〜28字目安（標準カテゴリ）
- 中部: 1行目12〜24字 + 2行目12〜24字（`chain_menu` の商品スライドのみ）
- 強調語: 1語または短い句

超過する場合は台本を短くする。画像プロンプトで長文を押し込まない。

## Label Notation (chain_menu)

`chain_menu` カテゴリでは、商品スライドの上部冒頭に固定ラベルを置く。

- `[増量]` 増量期向け商品
- `[減量]` 減量期向け商品
- `[両用]` どちらでも使える商品

例: `[両用] しまほっけ定食`

ラベルは画像生成プロンプトに含める日本語テキストの一部として、一字一句変更不可。色分け、絵文字、アイコンでの代替は使わない（画像生成AIが暴れる原因になるため）。

`chain_menu` の商品スライド中部は2行構成にする:

- 1行目: `P○g F○g C○g 約○○kcal`
- 2行目: 成分の効き1行

スラッシュ区切りは使わず、半角スペースで区切る。改行を明示してプロンプトに渡す。
